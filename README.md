# Demovote

Contest plateform for demoscene party, developed for the Alchimie parties (Tain l'Hermitage / France) organized by Association Triple A.

Features:
- visitors management
- chat
- schedule
- entries upload with infos 
- compos management, entries grouping
- entries presentation, by compos
- poll for each compo
- results presentation

Online instance at [https://www.triplea.fr/demovote](https://www.triplea.fr/demovote)
